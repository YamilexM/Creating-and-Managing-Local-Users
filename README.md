# Creating and Managing Local Users in Windows

## Objective

Create and manage a local Windows user account, review permissions, and perform a password reset.

## Step 1: Review Existing Local Users

Reviewed the existing local user accounts in **Computer Management**.

![](images/01-local-users-overview.png)

## Step 2: Create a New Local User

Created the **TMorgan** account and configured the user to change the password at next logon.

![](images/02-create-local-user.png)

## Step 3: Verify the User Account

Confirmed that the new local user was successfully added to the system.

![](images/03-local-user-created.png)

## Step 4: Review Group Membership

Verified that TMorgan belonged to the standard **Users** group and did not have administrative privileges.

![](images/04-standard-user-group-membership.png)

## Step 5: Review the Password Reset Warning

Initiated an administrative password reset and reviewed the Windows warning about potential effects on protected user data.

![](images/05-set-password-warning.png)

## Step 6: Verify the Password Reset

Confirmed that the password reset completed successfully.

![](images/06-password-reset-successful.png)
